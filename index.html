Welcome to simpleflying

simpleflying is a small 3d game made in python thanks to the Ursina engine module and free models of planes, the current version of simpleflying is the 0.0.0 Beta, this is still a Beta remember, it's not even close to being finished.


to download simpleflying ensure you have python installed, if not run:


for linux:
sudo apt install python3
for windows:
winget install python313
if python isn't installed on the machine, the installer will install it
